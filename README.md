This is a tower defense game inspired by Plants vs. Zombies.

The current game creates an 8x4 grid with room on the bottom and top. These areas will be used to provide the user with information on how to play the game, as well as other vital information about their "towers," such as what they do. As of right now, a cursor and a lone enemy are displayed at the beginning of the game. The cursor can be moved around by using WASD, and upon pressing on the number 1 on the keyboard, the user will have the ability to place a tower known as "teto." To finish this interaction, the user must then press the space bar to actually have the newly placed tower appear on screen. This is because I plan to include other towers which can also be selected for placement. Additionally, the user can remove a tower by pressing the "e" key. The lone enemy is able to move forward and will disappear once it reaches the end of the screen.

I had originally planned to get the tower and enemy to interact for this assignment, but I had trouble figuring out some of the mechanics for the game overall, and later ran into bugs which consumed my time. However, I believe that what I have so far can be used as a framework to include other towers and enemies. Additionally, I believe that outputting the information on the screen should be much simpler compared to what I've done so far since there are not as many moving parts. I also plan to incorprate a currency that will allow players to place towers if they have enough, as well as include a scoring system. The final vision for this game will likely be something that ends once an enemy reaches the end of the grid. I had originally planned to create levels, but that may not be possible due to time constraints.

In terms of the code, placing towers is currently performed in the Cursor class, whereas interactions between enemies and towers will occur in the TDGame class when implemented later. Some classes also have unused methods as of right now because I suspect they will be useful when implementing later mechanics.
